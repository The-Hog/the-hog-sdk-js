# People

## Overview

### Available Operations

* [search](#search) - Search people

## search

Async people discovery. Returns operationId; poll GET /api/operations/:id.

### Example Usage

<!-- UsageSnippet language="typescript" operationID="searchPeople" method="post" path="/api/v1/people/search" -->
```typescript
import { TheHog } from "@the-hog/sdk";

const theHog = new TheHog({
  security: {
    accessKey: process.env["THE_HOG_ACCESS_KEY"] ?? "",
    secretKey: process.env["THE_HOG_SECRET_KEY"] ?? "",
  },
});

async function run() {
  const result = await theHog.people.search({
    query: "VP Engineering at hiring B2B SaaS companies in SF",
  });

  console.log(result);
}

run();
```

### Standalone function

The standalone function version of this method:

```typescript
import { TheHogCore } from "@the-hog/sdk/core.js";
import { peopleSearch } from "@the-hog/sdk/funcs/people-search.js";

// Use `TheHogCore` for best tree-shaking performance.
// You can create one instance of it to use across an application.
const theHog = new TheHogCore({
  security: {
    accessKey: process.env["THE_HOG_ACCESS_KEY"] ?? "",
    secretKey: process.env["THE_HOG_SECRET_KEY"] ?? "",
  },
});

async function run() {
  const res = await peopleSearch(theHog, {
    query: "VP Engineering at hiring B2B SaaS companies in SF",
  });
  if (res.ok) {
    const { value: result } = res;
    console.log(result);
  } else {
    console.log("peopleSearch failed:", res.error);
  }
}

run();
```
